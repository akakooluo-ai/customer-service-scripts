# 家居用品行业客服话术

> 专业的家居用品行业客服话术模板，涵盖尺寸确认、材质说明、组装指导、配送安装等全链路场景。

## 使用说明

- 话术中的 `[变量]` 需要根据实际情况替换
- 家居行业 72% 的咨询集中在尺寸规格和组装说明
- 尺寸问题是退货主要原因，必须确认清楚

---

# 售前话术（5条）

## 1. 尺寸规格确认

**适用场景：** 客户询问产品尺寸、是否适合空间

```

Length: [Size] | Width: [Size] | Height: [Size]
Weight: [Weight]
Space needed: Allow [Extra space] around for [Doors/Drawers/Movement].
Measuring tip: Measure your space AND doorways for delivery!
Send us your room dimensions and we'll confirm if it fits! 🏠
```

## 18. 安装孔位不匹配处理

**适用场景：** 客户组装时发现孔位偏差、螺丝难拧

```

Please send:
• Photos of the hole alignment
• The step number in the manual
• The part labels involved

Sometimes lightly loosening nearby screws first can help align the frame. If parts are incorrect or defective, we'll send replacement parts right away.
```

```

Certifications: [Certification]. If the smell is strong, unusual, or does not fade, contact us with photos and batch information so we can escalate to quality review.
```

## 20. 颜色木纹差异说明

## 22. 桌椅晃动排查

**适用场景：** 客户反馈桌子、椅子、柜体组装后不稳

```

Please try:
1) Place it on a flat surface
2) Loosen all screws slightly
3) Adjust the frame evenly
4) Tighten screws diagonally

If it still wobbles, send a short video and we'll check whether replacement parts are needed.
```

## 使用技巧

1. **尺寸确认**：主动提供详细尺寸，建议客户测量空间和门宽
2. **组装支持**：提供视频教程链接，降低组装咨询量
3. **损坏快处理**：大件退货成本高，优先提供换件或部分退款
4. **配送沟通**：大件配送需预约，提前说明流程
