# 服装行业客服话术

> 专业的服装行业客服话术模板，涵盖尺码咨询、材质说明、搭配建议、退换货处理等全链路场景。

## 使用说明

- 话术中的 `[变量]` 需要根据实际情况替换
- 服装行业 70% 的咨询集中在尺码、材质、搭配三大问题
- 建议配合快捷回复软件使用，提升响应速度

# 售前话术（5条）

## 1. 尺码咨询

**适用场景：** 客户询问尺码、不确定选哪个尺码

```

## 18. 洗涤后缩水是否质量问题

**适用场景：** 客户按说明洗涤后仍缩水，质疑面料或描述

```

## 使用技巧

1. **尺码推荐**：主动询问客户身材数据，给出专业推荐
2. **真实描述**：材质、颜色、版型要如实描述，避免夸大
3. **视觉辅助**：配合尺码表图片、模特试穿图提升沟通效率
4. **快速换码**：尺码问题是最常见的售后问题，处理要快速高效
