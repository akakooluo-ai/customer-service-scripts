# TikTok Shop 售前客服话术

> 专业的 TikTok Shop 售前客服话术模板，涵盖直播带货、评论互动、私信咨询、产品推荐等社交电商场景。

## 使用说明

- 话术中的 `[变量]` 需要根据实际情况替换
- TikTok 用户年轻化，话术风格要轻松活泼
- 直播场景需要快速响应，建议配合快捷回复软件使用

---

## 1. 直播欢迎语

**适用场景：** 直播开场，欢迎观众

```
Welcome to our live! 🎉 Thanks for joining! We have amazing deals today with exclusive live-only discounts. Drop a ❤️ if you're excited! Follow us for more live shopping events. Let me show you our best products!
```

---

## 2. 直播产品介绍

**适用场景：** 直播中介绍产品

```
Let me show you this [Product Name]! 🔥 This is our bestseller with [Key Feature 1], [Key Feature 2], and [Key Feature 3]. Today's live price is only $[Price] - that's [Discount]% off! Limited stock available. Click the yellow cart to add to your bag!
```

---

## 3. 评论区回复

**适用场景：** 回复短视频评论区咨询

```
Hi! Thanks for your comment! 💕 Yes, we ship to [Country]! Shipping takes [Time] days. We have this in stock right now. Click the link in bio or shop during our next live for special discounts! Follow us so you don't miss it!
```

---

## 4. 直播限时优惠

**适用场景：** 直播中推出限时折扣

```
⏰ FLASH SALE ALERT! For the next 10 minutes only, get an EXTRA [Discount]% off on [Product Name]! This is our lowest price ever! Don't miss out - add to cart NOW! Only [Number] left in stock! 🛒
```

---

## 5. 尺码咨询回复

**适用场景：** 客户询问尺码建议

```
Great question! For sizing, we recommend: [Size Guide]. This runs [true to size/small/large]. Check our size chart in the product description. If you're between sizes, I suggest sizing [up/down]. We also offer free returns if it doesn't fit! 📏
```

---

## 6. 直播互动引导

**适用场景：** 引导观众互动、点赞、关注

```
Drop a 💚 if you want to see this in [Color]! Comment "LINK" and I'll send you the product link! New here? Hit that FOLLOW button for exclusive follower-only deals! Let's get to [Number] likes and I'll do a special giveaway! 🎁
```

---

## 7. 产品对比说明

**适用场景：** 客户询问不同产品的区别

```
Comparing [Product A] vs [Product B]: [Product A] is perfect for [Use Case 1] with [Feature]. [Product B] is better for [Use Case 2] with [Feature]. Both are on sale today! Which one do you prefer? Comment 1 or 2! 🤔
```

```

```

## 使用技巧

1. **快速响应**：直播和评论区要秒回，使用快捷回复软件
2. **亲切互动**：使用轻松活泼的语气，符合 TikTok 年轻化氛围
3. **引导下单**：提供购物车链接，简化购买流程
4. **制造紧迫感**：强调限时优惠、库存紧张，促进即时下单
5. **使用 emoji**：适当使用表情符号，增加亲和力
