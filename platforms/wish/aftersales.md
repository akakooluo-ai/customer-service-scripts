# Wish 售后客服话术

> 专业的 Wish 低价跨境电商售后客服话术模板，涵盖退换货处理、质量问题、包裹丢失、评价引导等售后服务场景。

## 使用说明

- 话术中的 `[变量]` 需要根据实际情况替换
- Wish 有买家保护政策，要善用平台保障
- 低价商品退货成本高，优先提供退款或补发

## Wish 售后话术列表（共 15 条）

### 1. 退货政策说明

**适用场景：** 买家咨询退货流程

```

Wish app → Order History → Request Return → Select reason

Process:
• We provide return label
• Refund processed within [Time] days after return received
• Items must be unused with tags

Easy returns! Questions? Ask us! ✨
```

## 使用技巧

1. **快速响应**：售后问题要及时处理，避免纠纷升级
2. **灵活方案**：低价商品退货成本高，优先提供退款
3. **买家保护**：善用 Wish 买家保护政策
4. **主动补偿**：问题解决后发放优惠，促进复购
5. **评价管理**：问题解决后再请求好评
