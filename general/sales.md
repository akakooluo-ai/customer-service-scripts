# 通用售中客服话术

> 适用于所有平台和行业的通用售中客服话术模板，涵盖订单确认、物流跟踪、支付处理、订单修改等场景。

## 使用说明

- 话术中的 `[变量]` 需要根据实际情况替换
- 这些话术适用于任何电商平台和行业
- 建议根据具体平台和产品进行个性化调整

---

## 1. 订单确认

**适用场景：** 客户下单后确认订单信息

```
Thank you for your order! 🎉

Order details:
• Order #: [Order Number]
• Product: [Product Name]
• Quantity: [Quantity]
• Total: $[Amount]

Shipping to: [Address]
Estimated delivery: [Date]

Please verify this information is correct. 
If you need to make any changes, let us know ASAP!
We'll notify you when your order ships. 📦
```

---

## 2. 发货通知

**适用场景：** 订单发货后通知客户

```
Great news! Your order has shipped! 🚚

Tracking information:
• Carrier: [Carrier Name]
• Tracking #: [Tracking Number]
• Estimated delivery: [Date]

Track your package: [Tracking Link]

Tips:
• Save this tracking number
• Check tracking for updates
• Contact us if no movement after [Days] days

Enjoy your purchase! 📦
```

## 3. 物流追踪

**适用场景：** 客户询问物流进度

```
Let me check your order status! 📦

Order #: [Order Number]

Current status: [Status]
Location: [Current Location]
Estimated delivery: [Date]

Track here: [Tracking Link]

```

## 5. 支付问题处理

**适用场景：** 客户支付失败或有支付疑问

```
I see there might be a payment issue! 💳

Please check:
• Card information is correct
• Billing address matches your card
• Sufficient funds available
• Card is not expired

If the issue persists:
• Try a different payment method
• Contact your bank
• Clear browser cache and try again

Need help? I can guide you through the process! 🛒
```

## 6. 订单修改

**适用场景：** 客户要求修改订单

```
I understand you'd like to modify your order! 📝

Order #: [Order Number]
Current status: [Status]

If your order hasn't shipped yet:
✓ We can change: [Editable Fields]
✓ Please confirm the changes you need

If your order has already shipped:
• Address change: We'll try to intercept with the carrier
• Item change: Please return and reorder, or wait for delivery and exchange

What changes do you need? 🔄
```

## 7. 订单取消

**适用场景：** 客户要求取消订单

```
I can help you cancel your order! 🛑

Order #: [Order Number]
Status: [Status]

If not yet shipped:
✓ Cancellation confirmed
✓ Refund processed within [Days] business days

If already shipped:
• We can try to intercept the package
• Or you can refuse delivery / return when received
• Refund after we receive the item back

Shall I proceed with the cancellation? 📦
```

## 8. 地址确认/修改

**适用场景：** 确认或修改收货地址

```
Let me verify your shipping address! 📍

Current address on file:
[Full Address]

Is this correct? 

If you need to change it:
• Before shipping: We can update immediately
• After shipping: We'll contact the carrier (may incur fees)

Please confirm or provide the correct address! 🏠
```

---

## 使用技巧

1. **主动通知**：订单确认和发货通知要主动发送
2. **信息准确**：确保订单号、追踪号等信息准确无误
3. **及时响应**：售中问题要在 2 小时内响应
4. **避免模糊**：给出具体时间，不要使用"尽快"等模糊表述
